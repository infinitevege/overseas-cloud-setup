# Azure 按项目分账：标签、资源组与预算提醒的用法

一个 Azure 订阅里往往跑着多个项目。月底老板问「A 项目花了多少」，如果答不上来，原因通常不是工具不够，而是资源组和标签一开始没规划。这篇讲一套简单可执行的分账方法。

> 订阅、租户、资源组的基础概念见 [Azure 开户前须知](https://www.clouddalao.com/guides/azure-subscription-types-and-quota)。

## 资源组定边界，标签补维度

| 工具 | 适合表达 | 特点 |
| :--- | :--- | :--- |
| 订阅 | 大的预算边界、权限边界 | 数量少，变更成本高 |
| 资源组 | 一个项目在一个环境下的全部资源 | 删除资源组会删除其中所有资源 |
| 标签 | 成本中心、负责人、环境等补充信息 | 一个资源可以有多个标签 |

推荐做法：**一个项目的一个环境 = 一个资源组**，例如 `rg-shop-prod`、`rg-shop-test`；再用标签记录跨资源组的信息，例如 `costcenter`、`owner`。

## 标签规范

1. 只定 3～5 个必填标签，例如 `project`、`env`、`owner`、`costcenter`。
2. 标签名统一小写，值也统一写法，`prod` 和 `Production` 会被当作两个值。
3. 注意：资源默认**不会**继承资源组上的标签。可以在 Cost Management 中开启标签继承，或用 Azure Policy 自动补齐缺失的标签。
4. 每月检查一次没有标签的资源，补齐后再出报表。

## 用成本分析出报表

在 Cost Management 的成本分析（Cost analysis）中：

- 范围选订阅，分组选「资源组名称」，得到按项目、按环境的费用；
- 分组改为某个标签，得到按成本中心或负责人的费用；
- 保存为视图，每月固定看同一张表，便于对比。

## 用预算做提醒

- 在订阅或资源组范围创建预算，设定月度金额。
- 设置实际费用和预测费用两类提醒，例如实际达到 80%、预测达到 100% 时通知。
- 预算本身只负责通知，不会自动关停资源；需要自动处理时可以结合操作组（Action Group）触发自动化。

## 和充值节奏配合

分账做清楚后，下个月的预估费用就有了依据。已经通过云大佬开通的 Azure 订阅，充值需要先与专人确认订阅信息，见 [国际云充值](https://www.clouddalao.com/recharge)；还没有订阅的团队可以先看 [Azure 开户说明](https://www.clouddalao.com/cloud/azure)。
