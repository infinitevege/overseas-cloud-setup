# 腾讯云国际费用中心怎么看：余额、账单明细与扣费记录

腾讯云国际（tencentcloud.com）的计费以小时为粒度的按量计费居多，余额每天都在变。看不懂费用中心，就很难回答两个最常见的问题：**钱花到哪去了？还能撑几天？** 这篇按页面讲清楚每个地方该看什么。

> 控制台的英文菜单通常叫 Billing Center，下面的页面名称是对应的中文说法，具体以控制台为准。

## 四个页面，各管一件事

| 页面 | 回答什么问题 | 什么时候看 |
| :--- | :--- | :--- |
| 账户概览（Overview） | 现在还有多少余额 | 每天 |
| 账单概览（Bill Overview） | 这个月一共花了多少、各产品占比 | 每周 |
| 账单明细（Bill Details） | 哪台实例、哪个资源产生了这笔费用 | 费用异常时 |
| 收支流水（Transaction Details） | 余额什么时候增加、什么时候被扣 | 充值后、对账时 |

## 用账单明细定位一笔扣费

1. 在账单明细里把时间范围缩小到费用异常的那一天。
2. 按「产品」分组，找出占比突然变大的产品，常见的是 CVM、云硬盘、公网流量和 CDN。
3. 展开到「资源 ID」，对照实例名称或标签找到具体资源。
4. 再看计费项：同一台 CVM 可能同时产生实例费、云盘费和带宽费，三者分开计费。

如果资源没有打标签，第 3 步会非常痛苦。建议从第一台机器起就给资源统一加标签。

## 估算还能撑几天

一个够用的算法：

```
可用天数 ≈ 当前余额 ÷ 最近 7 天日均消耗
```

最近 7 天日均消耗可以在账单概览里按日查看。这个数字低于 7 天，就应该准备充值；低于 3 天，当天就处理。

## 充值后怎么核对

已开通的腾讯云国际账号可以在 [国际云充值](https://www.clouddalao.com/recharge) 页按账号 UID 充值。到账后按这个顺序核对：

1. 订单页显示「已支付」并给出处理结果；
2. 收支流水里出现一条对应的入账记录，金额与订单的到账金额一致；
3. 账户概览的余额相应增加。

账号 ID 在哪里看、充值前后还要注意什么，见 [腾讯云国际账号充值流程](https://www.clouddalao.com/guides/tencent-cloud-international-top-up)。

## 两个容易误会的地方

- **余额充足不代表包年包月资源会自动续费。** 包年包月实例是否续费取决于续费设置，到期前要在续费管理里单独确认。
- **轻量服务器和 CVM 的计费结构不同。** Lighthouse 套餐通常包含一定流量，CVM 的流量单独计费，两者混用时要分开看账单。选型差异见 [Lighthouse 与 CVM 对比](https://www.clouddalao.com/guides/tencent-cloud-lighthouse-vs-cvm)。
